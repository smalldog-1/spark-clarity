# Spark Clarity ✨

将灵感火花转化为清晰思路的AI引导工具

## 概述

Spark Clarity 是一个系统化的想法澄清助手，通过结构化的提问和分析，帮助你把模糊的灵感整理成清晰、完整的产品概念。

与传统的头脑风暴或共识工具（如 "grill me"）不同，Spark Clarity 运行**双模式工作流**：**引导式问答**负责只有你自己知道的部分（缘起、概念、你想要的特色）；**AI 独立调研**负责客观部分（竞争格局、竞品痛点、根因、解法）——原因很简单：如果你能自行分析清楚市场，你就已经拥有清晰的思路，不需要这场对话。流程引导你：
- 通过问答探索想法的起源和动机
- 通过问答澄清核心概念（适度抽象，避免过早陷入细节）
- 由 AI 调研竞争格局（客观为何存在）
- 通过问答引出你的特色——你想让它成为什么（不与市场比对）
- 由 AI 深入剖析竞品痛点、根因与解决方案
- 最终输出一份简洁、切中要害、带内容来源标注的分析文档

## 工作流程

```
1. 缘起探索 → 为什么会有这个想法？          [问答]
          ↓
2. 概念澄清 → 你想做什么？（保持适度粒度）   [问答]
          ↓
3. 竞争格局 → AI 调研：同类产品及它们为何存在 [AI]
          ↓
4. 特色 → 你想让它成为什么？              [问答]
          ↓
5. 竞品深挖 → 痛点、根因、可能的解法       [AI]
          ↓
6. 文档输出 → 生成结构化的 Markdown 报告   [AI]
```

## 使用方法

### 作为标准 skill 安装

本仓库本身就是 skill 目录。把它 clone 到 pi 的 skill 目录即可被自动发现：

```bash
# 全局安装（当前用户所有项目可用）
git clone https://github.com/smalldog-1/spark-clarity.git ~/.pi/agent/skills/spark-clarity
# 项目级安装
cd your-project && git clone https://github.com/smalldog-1/spark-clarity.git .pi/skills/spark-clarity
```

然后开始新对话：当你的表达匹配 skill 描述时 pi 会自动加载，也可以强制加载 `/skill:spark-clarity`。兼容所有支持 Agent Skills 标准的工具（Claude Code：`~/.claude/skills/`）。

### 不安装直接使用

1. 把 `SKILL.md` 的内容粘贴进一段新对话
2. 开始对话，AI 会自动引导你完成整个流程
3. 按照提示一步步回答（问答阶段）
4. 最终获得一份完整的想法分析文档

### 典型对话流程

**AI**: Let's turn your spark into clarity. First, I want to understand the origin: **What sparked this idea for you? What made you think this needs to exist?**

**你**: [描述你的想法起源...]

**AI**: [针对性追问，逐步澄清概念...]

...

**AI**: [最终生成结构化文档]

## 特点

- **双模式分工**：问答负责你的主观洞察，AI 独立调研负责市场事实，两者绝不混用
- **系统化流程**：不是随机对话，而是明确的六个阶段
- **适度粒度**：避免过早陷入实现细节，保持概念层面的清晰
- **可信的竞品调研**：竞争格局与深挖由 AI 基于自身知识交付（标注 ⚡ AI-research）
- **文档输出**：自动生成结构化、可直接使用的分析报告，每条内容标注来源
- **一问一答**：专注、高效的交互方式

## 输出示例

最终生成的文档包含：
- 🎯 缘起与动机
- 💡 核心概念（目标用户、核心价值、关键场景）
- 🌍 竞争格局
- ✨ 特色与愿景（来自用户）
- 🔍 竞品分析（痛点、根因、解决方案）
- 🚀 战略定位
- 📋 关键洞察
