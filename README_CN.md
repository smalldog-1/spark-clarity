# Spark Clarity ✨

将灵感火花转化为清晰思路的AI引导工具

## 概述

Spark Clarity 是一个系统化的想法澄清助手，通过结构化的提问和分析，帮助你把模糊的灵感整理成清晰、完整的产品概念。

与传统的头脑风暴或共识工具（如 "grill me"）不同，Spark Clarity 专注于**将说不清的想法结构化**，通过明确的工作流引导你：
- 探索想法的起源和动机
- 澄清核心概念（适度抽象，避免过早陷入细节）
- 了解竞争格局
- 分析差异化优势
- 深入剖析竞品痛点和解决方案
- 最终输出一份简洁、切中要害的分析文档

## 工作流程

```
1. 缘起探索 → 为什么会有这个想法？
          ↓
2. 概念澄清 → 你想做什么？（保持适度粒度）
          ↓
3. 竞争格局 → 市场上有哪些类似产品？
          ↓
4. 差异分析 → 你的特色和优势是什么？
          ↓
5. 竞品深挖 → 现有方案的痛点、根因和可能的解决方案
          ↓
6. 文档输出 → 生成结构化的 Markdown 报告
```

## 使用方法

### 在 Claude 中使用

1. 将 `spark-clarity.md` 的内容作为自定义指令或项目知识库添加到 Claude
2. 开始新对话，AI 会自动引导你完成整个流程
3. 按照提示一步步回答问题
4. 最终获得一份完整的想法分析文档

### 典型对话流程

**AI**: Let's turn your spark into clarity. First, I want to understand the origin: **What sparked this idea for you? What made you think this needs to exist?**

**你**: [描述你的想法起源...]

**AI**: [针对性追问，逐步澄清概念...]

...

**AI**: [最终生成结构化文档]

## 特点

- **系统化流程**：不是随机对话，而是明确的六个阶段
- **适度粒度**：避免过早陷入实现细节，保持概念层面的清晰
- **竞品洞察**：帮助你理解市场现状和差异化机会
- **文档输出**：自动生成结构化、可直接使用的分析报告
- **一问一答**：专注、高效的交互方式

## 输出示例

最终生成的文档包含：
- 🎯 缘起与动机
- 💡 核心概念（目标用户、核心价值、关键场景）
- 🌍 竞争格局
- ⚡ 差异化优势
- 🔍 竞品分析（痛点、根因、解决方案）
- 🚀 战略定位
- 📋 关键洞察

## 适用场景

- 产品经理梳理新产品想法
- 创业者验证创业方向

- 设计师明确设计方向
- 任何需要将模糊灵感转化为清晰方案的场景

| 传统头脑风暴 | 发散思维 | 自由联想 |
